# Research Notes

## Initial Project Direction

Overall topic:
Vision-based gait recognition.

The goal of Project 1 is to establish a simple biometric identification baseline that can later be expanded in Projects 2 and 3.

## Current Direction

Potential primary dataset:
CASIA-B

Potential baseline representation:
Gait Energy Image (GEI)

GEI is considered because it is simple, interpretable, and appropriate for establishing a baseline before investigating stronger representations later.

## Dataset and Representation Investigation

### CASIA-B
- 124 subjects
- Multiple walking sequences
- 11 viewing angles
- Normal, bag, and clothing conditions
- Silhouette data available
- Good for a controlled baseline
- Useful for later viewpoint/clothing experiments

### GREW
- Much larger, real-world gait dataset
- Silhouettes, GEIs, and pose-based representations
- More realistic but more complex
- Better suited for later advanced experiments / capstone project (project 3)

## Current Decision

For Project 1, CASIA-B is currently preferred because it provides a simpler, controlled environment and silhouette data suitable for building a low-complexity baseline biometric system.

GEI is currently preferred as the baseline representation because it is simple, interpretable, and computationally inexpensive. It also provides a useful reference point for comparing more advanced sequence-based, skeleton-based, or multimodal gait representations in Projects 2 and 3.

This decision may still change if dataset access or further experimentation shows that another option is more suitable.
